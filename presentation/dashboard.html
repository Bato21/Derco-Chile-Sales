Prediction · Model B

Model B — loss-deal classifier

HistGradientBoosting · pre-sale features only
Trained on brand, channel, comuna, list price and timing. Margin is excluded — the target is derived from it, so including it would be leakage and the model would simply read the answer.
How this gets used. The pricing team reviews the riskiest 10% of open deals. That review catches of all below-cost deals — better than reviewing at random.

Honest limit. Losses are 2.18% of deals, so PR-AUC is 0.142 against a 0.022 base rate: modest in absolute terms, ~6.5× the base rate. This is a triage aid, not an auto-reject — a human reviews every flag.
Metrics read from metrics.json, written by the notebook — not typed into this page. Stratified hold-out plus 5-fold CV.
